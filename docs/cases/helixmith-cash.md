## 원문과 정답 초안

재무상태표 위치: III. 재무에 관한 사항 → 2. 연결재무제표 → 2-1. 연결 재무상태표. 단위는 **원**이고 제30기(2025년 말) 열을 선택합니다.

| 항목 | 제30기 | 제29기 |
|---|---:|---:|
| 현금및현금성자산 | **31,827,123,947원** | 36,840,718,479원 |

주석 위치: 같은 장 → 3. 연결재무제표 주석 → 6. 현금및현금성자산 (1). 단위는 **천원**이며 당기말 열을 선택합니다.

| 구성 | 당기말(천원) | 전기말(천원) |
|---|---:|---:|
| 보통예금 | 5,984,959 | 36,540,115 |
| 외화예금 | 694,245 | 300,603 |
| 정기예금 | 25,147,920 | 빈칸 |
| 계 | **31,827,124** | 36,840,718 |

주석에 적힌 당기말 세부항목의 합계는 주석 합계와 같습니다. 다만 원 단위로 바꾼 주석 합계는 **31,827,124,000원**으로, 재무상태표 금액보다 **53원 큽니다**.

- 주석 내부 합계: 일치.
- 재무상태표와 주석의 정확한 원 단위 비교: 53원 차이.
- 차이의 원인과 자동 허용 여부: 확인 필요. 천원 표시와의 관계를 볼 수 있지만 반올림 방식이 명시됐다고 단정하지 않습니다.
- 보유 목적: 이 자료만으로 추정하지 않습니다.

표시금액을 단순 반올림해 53원 차이를 숨기거나, 작은 차이라는 이유로 곧바로 기업 오류라고 쓰지 않습니다. 총액으로 어느 값을 사용할지와 오차 허용 정책은 다음 논의에서 정합니다.

## 혼동하면 안 되는 값

같은 공시의 별도 주석 6번에는 당기말 합계가 **31,653,155천원**으로 나옵니다. 제목이 같아도 연결 값과 섞으면 안 됩니다. 연결 주석의 전기말 합계 **36,840,718천원**도 이번 당기말 값으로 쓰면 안 됩니다. 전기말 정기예금의 빈칸도 임의로 0으로 채우지 않습니다.

## 파일과 검토 상태

자료는 `tests/fixtures/cash/helixmith-2025/`에 둡니다.

- expected-draft.json: 원문 값·위치·합계·차이·해시를 수동 대조해 적은 초안.
- consolidated-note-table.html: 연결 주석의 표만 원문에서 잘라낸 자료.
- separate-note-table.html: 별도 주석과 혼동하지 않도록 보관한 비교 표.
- context.txt: 전체 문서에서 뽑은 기간·단위·절 설명. 원래 HTML 배치를 재현한 파일은 아닙니다.

전체 보고서는 저장하지 않았습니다. 잘라낸 표에는 상위 제목과 단위가 빠져 있으므로 표만 주고 단위를 알아냈다고 평가하면 안 됩니다. 이 자료는 파서의 최종 입력 형식을 정한 것이 아닙니다. 다른 법인과 감사보고서 형식에 대한 검증도 아직 없습니다.

## 준비할 실패·판단 보류 사례

| 사례 | 기대할 처리 | 자료 종류 |
|---|---|---|
| 당기 대신 전기 열 선택 | 기간 불일치를 표시 | 실제 두 열을 대조 |
| 별도 표를 연결 값으로 선택 | 범위 불일치를 표시 | 실제 두 표를 대조 |
| 원문 단위·문맥을 입력에서 제거 | 추정하지 않고 확인 필요 | 원문을 가공한 테스트 입력 |
| 세부항목 하나를 제거 | 완전한 내역으로 합계 확정하지 않음 | 원문을 가공한 테스트 입력 |
| 재무상태표와 주석 비교 | 53원 차이를 보존하고 판정은 보류 | 실제 공시의 표시 단위 차이 |

단위 제거·항목 삭제는 기업이 그렇게 공시했다는 뜻이 아닙니다. 테스트용 변형이며 원본과 별도 파일·식별자로 관리합니다. 변형 파일과 추출 테스트는 사용자 확인 후 작성합니다.
