- 대상: 이슈·PR·계약/규칙·코드 커밋
- 목적과 변경 전 비교 대상:
- 실행 조건: 날짜, 도구·모델·프롬프트·사례 버전, 개발용/별도 검증용
- 실행 한도와 실제 사용: 시간·호출·비용·재시도 (알 수 없으면 미측정)
- 실행 근거: 명령·CI 링크·산출물·원문 위치
- 결과: 확인한 필드와 사례 수, 통과·실패·보류·누락, 회귀 여부
