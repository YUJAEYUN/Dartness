# 공시 테스트 사례 기록

공시에서 정답을 확인할 때 사용합니다. 확인하지 못한 내용은 비워두거나 확인 필요로 적습니다.

## 자료와 목적

- 사례 ID와 법인:
- 문서 종류·출처 URL·확인일:
- 원문 해시와 발췌 파일:
- 개발용 / 별도 검증용 / 원문을 가공한 사례:
- 에이전트 작성·사용자 검토 상태:

## 무엇을 확인하나요?

- 관련 docs 규칙:
- 요청 기준일·연결/별도·통화:
- 원문의 절·표·행·열·단위 근거:
- 기대 값과 상태:
- 합계 범위와 차이:
- 선택하면 안 되는 비교 값:

## 어떻게 정답을 확인했나요?

원문 대조와 계산 과정을 적습니다. 구현 함수의 출력만 복사하지 않습니다. 원문에 없는 값·의도·오차 허용 정책을 추가하지 않습니다.

정정 관계, 생략 항목, 반올림 등 미확인 사항과 필요한 다음 행동을 적습니다.
