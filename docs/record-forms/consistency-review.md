# 정합성 검토 기록 양식

필요한 규칙만 묶어 PR 본문 또는 docs의 관련 기록으로 사용합니다. 별도 파일을 항상 만들 필요는 없습니다.

## 범위와 버전

- 대상 규칙·문서:
- 검토 대상 커밋(전체 SHA):
- 검토일·검토자(사람 또는 에이전트):

기록 자체가 포함된 커밋의 SHA를 미리 적지 않습니다. 비교한 기준 커밋과 작업 트리 차이를 적거나, 커밋 이후 PR에서 해당 SHA를 기록합니다.

## 근거와 판정

| 규칙 | docs 위치 | 구현·테스트 위치 | 위키 위치 | 관계별 상태와 이유 |
|---|---|---|---|---|
| 식별자 | 원문 링크·절 | 미구현 또는 실제 위치 | 실제 위치 | 일치 범위·차이·보류 이유 |

## 검증과 한계

실행한 명령·결과, 읽은 코드·사례, 확인하지 못한 범위를 구분합니다. 자동 검사는 의미 검토와 구별합니다.

## 후속 조치

수정할 대상과 이유, 필요한 논의, 다음 재검토 조건을 적습니다. 차이가 없어도 근거가 부족하면 판단 보류로 남깁니다.
