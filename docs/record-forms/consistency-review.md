# 문서·위키·코드 비교 기록

관련 내용이 서로 맞는지 확인할 때 사용합니다. PR 본문에 작성해도 됩니다.

## 무엇을 확인했나요?

- 확인한 규칙과 문서:
- 확인한 커밋 또는 PR:
- 확인한 날짜와 사람·에이전트:

커밋 전이라면 기준 커밋과 아직 커밋하지 않은 변경을 적어주세요. PR에서 최종 커밋을 연결해도 됩니다.

## 서로 맞았나요?

| 확인할 규칙 | 문서 링크 | 코드·테스트 링크 | 위키 링크 | 확인 결과와 이유 |
|---|---|---|---|---|
| 규칙 이름 또는 ID | 해당 문단 | 없으면 아직 구현 안 됨 | 해당 문단 | 맞는 점·다른 점·확인하지 못한 점 |

## 어떻게 확인했나요?

실행한 검사와 결과, 직접 읽은 코드나 사례를 적어주세요.
링크가 열리거나 테스트가 통과했다는 것만으로 설명과 동작이 일치한다고 판단하지 마세요.

## 다음에 할 일

고칠 내용과 이유를 적어주세요. 근거가 부족하면 확인하지 못했다고 남겨주세요.
