# 설계 결정 양식

영향이 크거나 나중에 되짚을 선택에만 사용합니다. 제목을 실제 결정으로 바꾸고 이 안내는 제거합니다.

## 상태와 배경

제안 / 합의 / 대체됨. 해결할 문제와 제약, 합의 근거를 적습니다.

## 결정과 이유

무엇을 선택했고 왜 적합한지 적습니다.

## 대안과 영향

검토한 대안, 선택하지 않은 이유, 얻는 점과 부담을 적습니다.

## 재검토 조건

어떤 새로운 근거나 상황에서 다시 판단할지 적습니다.

## 관련 근거

기준 문서, 구현·검증, 논의 링크를 연결합니다. 아직 없는 것은 미구현으로 표시합니다.
