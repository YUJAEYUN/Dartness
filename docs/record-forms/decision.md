# 설계 결정 기록

중요한 선택을 했을 때 사용합니다. 제목을 결정한 내용으로 바꾸고 이 안내는 지워주세요.

## 어떤 문제를 해결하나요?

배경과 지켜야 할 조건을 적어주세요.

## 무엇을 결정했나요?

상태: 논의 중 / 결정됨 / 다른 결정으로 변경됨

선택한 방법과 이유를 적어주세요. 관련 논의가 있으면 연결해주세요.

## 다른 방법도 검토했나요?

다른 방법을 선택하지 않은 이유와 이번 선택의 장단점을 적어주세요.

## 언제 다시 검토해야 하나요?

상황이 어떻게 바뀌면 이 결정을 다시 살펴봐야 하는지 적어주세요.

## 관련 자료

문서·코드·테스트 링크를 붙여주세요. 아직 구현하지 않았다면 그대로 적어주세요.
