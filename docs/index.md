# Dartness 설계 문서

사용자가 정한 조건을 DART에서 조회하고, 필요한 정보만 읽기 쉬운 고정 형식으로 제공합니다.

!!! info "설계 진행 중"
    합의한 요구사항과 기술 제안을 구분합니다. 문서 사이트 구성은 설정했지만 조회 엔진·스키마·모듈 구조는 아직 확정하지 않았습니다.
