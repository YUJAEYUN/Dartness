# 현금 표 추출 첫 평가 — DART 2025 사업보고서 6곳

상태: 2026-11-23 첫 실행 결과입니다. 이 결과를 보고 추출기를 고치면, 이 사례들은 더 이상 별도 검증용이 아니라 개발용이 됩니다([테스트 작성 방법](../testing.md)).

## 한눈에 보기

추출기는 **틀린 금액을 한 번도 내지 않았습니다.** 하지만 DART 원문을 그대로 넣으면 **11개 중 하나도 읽지 못했습니다.**

| 조건 | 맞음 | 확인 필요 | 틀림 |
|---|---|---|---|
| A. DART 원문 그대로 | 0 | 11 | 0 |
| B. 셀 태그 `<TE>`만 `<TD>`로 바꾼 변형 입력 | 7 | 4 | 0 |

## 무엇을 평가했나

- **대상:** 삼성전자, 농심, 셀트리온, 카카오, 현대건설, 리노공업의 2025 사업보고서(원본, 정정 전). 별도 6건, 연결 5건으로 모두 11건입니다. 리노공업은 연결 재무제표가 없습니다(OpenDART 연결 자료 없음, 원문에도 연결 재무상태표 없음). 그래서 개별(individual)로 넣었습니다.
- **구분:** 별도 검증용입니다. 추출기 개발에 쓰지 않은 법인입니다.
- **추출기:** main의 c1ec112 시점 `src/dartness/cash_table.py`, 수정하지 않았습니다.
- **입력 구간:** 원문 XML의 "2-1. 연결 재무상태표" 또는 "4-1. 재무상태표" 아래 첫 두 TABLE(기간·단위 표, 금액 표)을 그대로 잘라 넣었습니다. 추출기 설계상 구간 선정은 상위 단계의 몫이라, 사람이 고르는 방식을 그대로 흉내 냈습니다.
- **요청:** 기준일 2025-12-31, 연결 구간은 연결 범위, 재무상태표 구간은 법인 자체 범위로 요청했습니다.

## 정답은 어떻게 정했나

추출기를 돌리기 전에 원문 표에서 현금및현금성자산 행, 당기 열, 단위를 읽어 원 단위로 바꿨습니다. 11건 모두 OpenDART 재무제표 API(`fnlttSinglAcntAll`)의 별도·연결 값과 같았습니다. 원문 대조와 API 대조는 에이전트가 했으며, 사람의 독립 검토는 아닙니다.

## 실패 원인

**A. `<TE>` 태그 (11건 전부):** DART 원문 XML은 표 셀을 `<TD>`가 아니라 `<TE>`로 씁니다. 추출기는 `<TD>`·`<TH>`만 셀로 읽기 때문에 제목 칸부터 비어 보입니다. 그래서 "표 제목이 다릅니다"로 확인 필요를 돌려줍니다. 지금까지의 개발 사례(헬릭스미스)는 KIND의 HTML이라 `<TD>`를 썼습니다. **원문 수집(C 단계)이 받는 형식과 추출(D 단계)이 읽는 형식이 서로 맞지 않습니다.**

**B. 계정명 뒤의 주석 번호 (4건):** 삼성전자와 셀트리온은 계정명을 "현금및현금성자산 (주4,29)"처럼 씁니다. 추출기는 이름이 정확히 "현금및현금성자산"인 행만 찾기 때문에, 현금 행을 못 찾았다고 확인 필요를 돌려줍니다.

B 조건에서 맞은 7건은 단위가 원·백만원으로 섞여 있고 3개 기간 열이 있어도 정확했습니다. 변이 테스트에서 걱정했던 왼쪽 위 "과목" 칸은 11건 모두 비어 있어 문제가 되지 않았습니다.

## 실행 근거

- 수집: [Collect DART filings 실행 45094721526](https://github.com/YUJAEYUN/Dartness/actions/runs/45094721526). 원문은 `data/dart-filings-45094721526` 브랜치에 있습니다. 요청 25회, 실패 0건, 약 10분 걸렸습니다.
- 평가 자료: tests/fixtures/cash/dart-2025-eval (구간 원문, 해시, 정답, API 대조값)
- 회귀 테스트: tests/test_cash_eval_2025.py. 두 조건 모두에서 추출기가 **틀린 금액을 내지 않는지**만 고정합니다. 맞은 개수는 고정하지 않아, 추출기를 고쳐도 테스트가 깨지지 않습니다.
- 비용: OpenDART 무료 API만 썼습니다. 모델 호출은 없습니다.

## 해석과 한계

- 틀린 금액이 없다는 것은, 모르면 확인 필요로 남기는 설계가 의도대로 동작했다는 뜻입니다. 다만 6개 법인 11건이라 전체 공시 성공률을 말할 수는 없습니다.
- 대형 법인 위주이고, 모두 12월 결산·2025년 사업보고서입니다. 분기보고서, 정정 공시, 다른 결산월, 금융업 서식은 다루지 않았습니다.
- 구간은 사람이 고르는 방식으로 잘랐습니다. 보고서 전체에서 구간을 자동으로 찾는 일은 평가하지 않았습니다.
