# 최신 공시 선택: 동진쎄미켐 추가 법인 검증

상태: 2026-11-26, 구현 고정 뒤 원문 정답을 먼저 기록하고 실행했습니다. 이 법인은 최신 공시 선택 기능의 개발에 사용하지 않았고 평가 후 제품 코드를 수정하지 않았습니다. 전체 시장이나 M1 전체 E2E의 성공률은 아닙니다.

## 방법과 범위

구현 커밋 203c1e7383e419d5f9c5dca3a3896afdc460868b를 고정했습니다(PR #106, 병합 e394b317f17cad1f70c62e569198c779f4b85da5). 별도 계획과 정답 기록의 시각, 원문/웹 해시·고정 데이터 커밋과 실행 결과는 [검증 기록](../evidence/dongjin-latest-cash-2026.json)에 있습니다.

1. 공식 corpCode/기업개황/공시 목록에서 동진쎄미켐(005290, 00118804, 12월 결산)을 확인했습니다.
2. 2026-03-19~11-26 전체 유형 이력을 요청 9회로 받아 26건을 재검사했습니다. 사업·첫 분기·반기·최근 분기 보고서 총 4개 원문을 확보하고 ZIP/본문 멤버 해시를 확인했습니다.
3. 실행 전에 최근 분기 원문 BS_S/BS_C의 날짜 표·단위·현금 행을 직접 읽고 기대값을 기록했습니다. 수집기에 포함된 재무제표 API 응답을 정답으로 사용하지 않았습니다.
4. 같은 고정 코드로 요청 5개를 실행했습니다. 원문 접수번호·실제 날짜·범위·원시 숫자·단위·정확한 원화 값·조건 판정을 모두 대조했습니다. 두 재무상태표 웹 구간도 직접 열어 검증했고 JSON과 세 열 엑셀을 생성했습니다.

수집 실행은 [원본/개황](https://github.com/YUJAEYUN/Dartness/actions/runs/45735536773), [전체 유형 이력](https://github.com/YUJAEYUN/Dartness/actions/runs/45735764163), [첫 분기/반기](https://github.com/YUJAEYUN/Dartness/actions/runs/45735929253), [최근 분기](https://github.com/YUJAEYUN/Dartness/actions/runs/45735934527)입니다. API 총 18회와 별도 공식 웹 3회(본문 1·재무상태표 2)를 사용했고, 요청별 제한과 기존 권한을 유지했습니다. 일반 CI가 실제 DART를 호출한 결과로 표현하지 않습니다.

## 해석과 남은 범위

- 새 법인 1곳의 서로 관련된 요청 5개입니다. 회사 5곳·독립 표본 5개로 세지 않습니다.
- 이 사례에는 정기보고서의 정정·철회가 없습니다. 실제 정정 근거는 기존 HD건설기계 개발용이고, 누락·추가 차수·첨부·철회·순서 불명 방지는 합성/변형 테스트입니다. 이번 결과로 모든 정정 유형을 검증했다고 하지 않습니다.
- 지정한 이력 구간의 지원 정기보고서 실행입니다. 해당 구간 밖 자료·장중 추가 제출·전체 상장법인 명부·전수 원문 수집·주석 합계·금융업/외화·모든 보고서 서식·제품 최종 엑셀은 검증하지 않았습니다.
- Excel 파일을 재열어 수치·링크·10포인트/왼쪽 정렬·미충족 행 제외를 확인했습니다. 실제 Excel 데스크톱 렌더링과 운영 UI의 모바일/클릭 E2E는 수행하지 않았습니다.
