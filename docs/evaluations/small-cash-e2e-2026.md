상태: 2026-11-26 실제 새 수집과 결과·원문·엑셀 대조를 마쳤습니다. 전수 확대 이전의 연결 검사이며 새로운 독립 추출 성능 평가가 아닙니다.

## 범위와 성공 기준

공개 종목 005290(동진쎄미켐), 267270(HD건설기계)을 명시합니다. 합성 전수 명부를 만들지 않습니다. 공식 법인 코드 ZIP과 기업개황을 새로 받아 상장 구분·코드·현재 이름을 대조합니다. 2026-11-01부터 실행일까지 전체 유형 이력을 받고 해당 구간의 정기보고서 전체(법인당 1~2건)를 확보합니다. 최신 선택은 **이 제출일 구간 안의 자료**에 한정하며 구간 밖 공시의 완전성을 주장하지 않습니다.

별도 기준·최근 모드·재무 자료 허용 12개월·500억원은 이번 표본 실험 조건입니다. 사용자가 입력하는 제품 조건이나 별도/개별 자동 판정을 새로 확정하지 않습니다. 기존 query_latest_cash를 사용하며 정정 근거가 없으면 확인 필요로 남깁니다.

완료 기준은 새 수집 파일·원문 해시·요청 수·시간·크기·모든 표본의 상태가 남고, 확인된 충족 법인만 기존 세 열 엑셀로 출력되는 것입니다. 실패 법인을 미충족/0원으로 바꾸지 않습니다. 원문과 금액·날짜·단위를 대조하며 기존 실제 개발용 기대값과도 비교합니다. 수집이나 지원 범위 실패가 있으면 성공으로 숨기지 않습니다.

## 실행과 안전 경계

Collect DART filings를 small_cash_e2e 모드로 수동 실행합니다. stock_codes에 위 두 종목, history_start/history_end에 제출일 구간을 명시합니다. 기존 시크릿·contents 쓰기 권한으로 공개 자료와 결과를 별도 data/dart-filings-실행번호 브랜치에 보관하며 main에 합치지 않습니다. 기존 런타임 requirements.txt만 설치합니다.

API 20회·웹 6회가 전체 실행의 상한이며 실패한 시도도 셉니다. 자동 재시도는 없습니다. 원문 다운로드 32MiB·웹 2MiB와 기존 ZIP 제한을 재사용합니다. 기업개황/목록 오류·정기보고서 0건 또는 2건 초과·미지원 정정·본문 관측 실패는 확인 필요로 보존합니다. 일부 실패도 report.json과 빈/부분 matches.xlsx를 남기며 프로세스 성공은 모든 금액의 검증 성공을 뜻하지 않습니다. all_values_verified와 법인별 상태를 봐야 합니다. 실패 시 재시도와 남은 예산은 사람이 기록을 보고 판단합니다.

최종 파일은 기존 왼쪽 정렬·10pt·세 열 형식입니다. 내부 보고서는 모든 대상·원시 응답·목록/원문/본문 해시·시각·요청 파라미터를 보존합니다. 표 링크 대조 실패는 원래 공시 링크와 미확인 사유를 유지하며 금액을 추정하지 않습니다. 저장 폴더가 이미 있으면 덮어쓰지 않습니다. 이 경로에는 캐시·재개·전수 명부·별도/개별 자동 판정 기능이 없습니다.
