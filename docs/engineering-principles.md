# 에이전트 개발 원칙

상태: 2026-11-20 사용자가 다섯 원칙을 적용하는 방향에 동의했습니다. docs가 사람이 읽는 기준 원본이며 위키는 탐색 지도입니다. 이미 있는 검사와 절차를 연결하고, 없는 자동화를 완료했다고 표현하지 않습니다.

## 다섯 원칙과 적용 위치

| 원칙 | 적용 방식 | 현재와 남은 일 |
|---|---|---|
| Harness Engineering — 실행 환경과 제약 | 타입·린트·테스트·CI·브랜치 보호, 중단과 복구 조건 | 기존 Python·UI 검사와 보호 사용. 원문 의미 정확성과 모든 안티패턴을 자동 보장하지 않음 |
| Agent-first Repository — 에이전트가 탐색하기 쉬운 저장소 | 짧은 AGENTS, 위키의 원본·코드·검사 위치, 재현 명령 | 기존 구조 유지. 위키를 별도 규칙 원본으로 만들지 않음 |
| Spec-driven / Contract-first — 명세·계약 우선 | 기능별 입력·출력·예외·금지 동작·근거·완료 기준을 구현 전에 작성 | 금액 단위와 현금 Python 계약 생성 검증 구현. 현금 원문 추출·외부 JSON 경계는 후속 작업 |
| Evaluation-driven — 실행 결과로 개선 | DART 결과와 개발 과정의 평가를 분리하고 조건·근거·실패를 기록 | 실제 DART 수집과 오프라인 검사 존재. 별도 검증용 공시 집합·평가 실행기는 아직 없음 |
| Autonomous Development Loops — 제한된 자동 반복 | 이슈·명세·구현·검사·수정·PR·병합·기록 | 작업 중인 에이전트가 위임 범위에서 수행. 상시 봇·무제한 재시도는 없음 |

## 기능을 시작할 때

관련 docs와 계약 버전을 확인하고 기대 동작·예외·검증 방법을 이슈에 기록합니다. 정답과 검사 조건은 구현 결과에 맞춰 바꾸지 않습니다. 필요한 타입·스키마·계약 테스트는 해당 기능 PR에서 추가하고, 사람이 확인할 의미와 기계가 확인할 항목을 구분합니다. 가벼운 문구 수정마다 별도 계약이나 형식적인 테스트를 만들지는 않습니다.

## 자동 반복의 경계

[위임 정책](delegation.md)의 권한과 승인 범위를 유지합니다. 작업 시작 시 변경 범위·실행할 검사·재시도 한도·시간/호출/비용 한도를 필요한 범위에서 정합니다. 유료 모델이나 전체 법인 수집처럼 한도가 필요한 실행은 한도 없이 시작하지 않습니다.

실패하면 원인과 구체적인 수정 근거를 확인한 뒤 관련 검사를 다시 실행합니다. 같은 원인이 반복되거나 새 근거 없이 재시도하게 되면 중단하고 시도·미해결 원인·다음 선택을 보고합니다. 반복을 끝내기 위해 정답·검사·권한을 약하게 바꾸지 않습니다. 최종 검사한 head와 최신 main을 확인해 병합하고 이슈·문서·브랜치를 정리합니다.

## 무엇을 측정하나요?

| 평가 대상 | 기록할 내용 |
|---|---|
| DART 조회 | 법인·범위·시점·단위·금액·근거 정확성, 잘못된 확정·누락·확인 필요, 실행 시간·호출·비용 |
| 에이전트와 실행 환경 | 명세 준수·검사 우회 여부, 회귀, 수정 반복·사용자 개입과 원인, 소요 시간·확인 범위 |

실패한 실행도 남기고, 분모·기준 정답·확인 필드 없이 성공률을 만들지 않습니다. 모든 결과를 보류하는 것도 성공으로 보지 않습니다. 도구가 비용·시간을 제공하지 않으면 미측정으로 남깁니다. 모델·프롬프트·도구·사례 버전을 기록해 조건이 다른 결과를 섞지 않습니다. 개선 효과를 주장하려면 같은 작업 집합과 조건으로 변경 전후를 비교합니다.

[테스트 절차](testing.md)에 따라 개발용과 별도 검증용을 구분합니다. 검증 사례를 보고 수정했다면 개발용으로 전환하고 새 사례로 평가합니다. [평가 기록 양식](record-forms/evaluation.md)은 실행 증거를 남기는 용도이며 점수나 자동 평가기를 대신하지 않습니다.

## 사용자 관리 화면

사용자는 결정할 질문, 막힌 작업, 완료 요약, 원본 검사·PR·평가 기록을 확인합니다. 현재 화면은 GitHub 상태 스냅샷과 docs 링크를 제공합니다. 개발 평가 지표와 계약 충족 여부를 자동 집계하는 기능은 후속 범위입니다. 스냅샷이 오래되거나 조회에 실패했으면 정상으로 표시하지 않습니다.
