# 지정 공시 한 건의 현금 조건 실행

M1의 첫 체크포인트입니다. [상위 목표](https://github.com/YUJAEYUN/Dartness/milestone/1)는 실행일 현재 상장법인 전수·사용자 금액 조건·근거 포함 엑셀입니다. 이 체크포인트는 지정된 공시 원문 ZIP에서 표 구간을 자동 선정하고 현금 금액을 비교하는 경로이며 전수/최신 유효 정정 선택 완료가 아닙니다.

## 입력과 지원 범위

기존 Disclosure·CashQuery, 명시적 CashBasis·확인 시각·0 이상의 정확한 원화 최소 금액을 받습니다. 별도/개별 기본 정책은 유지하며 basis는 상위 단계가 확인해 전달합니다. 별도와 개별을 DART 표 태그만 보고 자동 구분하지 않습니다.

원문은 기존 read_archive의 크기/중복 제한을 거칩니다. 본문은 접수번호와 정확히 같은 이름의 XML 하나이며 첨부 XML을 대신 읽지 않습니다. 첫 지원은 UTF-8 사업보고서(ACODE 11011)의 DOCUMENT·COMPANY-NAME 법인 식별과 TABLE-GROUP ACLASS {XBRL}BS_S 또는 {XBRL}BS_C입니다. 해당 구역이 없거나 중복·중첩·미완성이면 확인 필요입니다. 모든 공시가 이 형식이라는 뜻은 아닙니다.

원문 전체가 일반 XML 문법에 맞지 않는 실제 공시가 있어 HTMLParser로 명시적 구조를 읽습니다. 원문을 자동 보정하거나 정규식으로 첫 금액을 고르지 않습니다. 선언된 외부 엔티티/DOCTYPE는 지원하지 않습니다. 원본 바이트 SHA-256과 UTF-8 텍스트의 구역 위치·구역 해시를 구분해 보존합니다. 기존 표 추출기는 선택 구역의 날짜·단위·행/열·범위를 검사합니다.

## 조건과 결과

CashValue가 나오면 정확한 amount_krw >= min_amount_krw를 비교합니다. 조건은 표시 반올림 값으로 비교하지 않습니다. 값 없음·추출 실패·지원하지 않는 구조는 needs_review이며 조건 미충족이나 0원이 아닙니다. 네트워크/ZIP 오류도 원인을 기록하며 다른 문서로 대체하지 않습니다.

결과는 document_match / document_non_match / needs_review이며 항상 run_scope=specified_report_only, latest_correction_verified=false입니다. 지정 문서의 금액 조건 비교이지 최종 법인 선정 자격은 아닙니다. 법인·공시·요청/실제 날짜·범위·원문 숫자/단위·전체/구역 해시·표/셀 위치·출처·실패 이유를 남깁니다. 최종 제품용 엑셀에는 이 체크포인트 결과를 최신 자료 선정 완료로 섞지 않습니다.

## 실제 사례와 검증

대한약품 원본 20260318001361의 전체 ZIP은 기존 공개 데이터 브랜치 data/dart-filings-45114584895에 보존돼 있습니다. 이 법인은 기존 계정명 수정에 사용한 개발용이며 미사용 검증용이 아닙니다. 기존 cases.json에 원문 대조로 고정한 2025-12-31 개별 현금 43,972,786,132원을 재사용합니다. 500억원 조건은 이 문서에서 미충족, 400억원 조건은 충족입니다. 기존 정답·기대값은 바꾸지 않습니다. 단위·기간·법인·구역 중복/첨부·조건 경계 실패는 합성/변형 사례로 구분합니다.

## 실행·출력 준비

첫 실행은 저장된 공개 원문을 사용해 API 호출 없이 확인합니다. 결과 JSON과 사람이 읽는 엑셀 미리보기는 제품 최종 양식과 구분합니다. 정식 엑셀 작성 의존성이 현재 프로젝트에 없으므로 범용 라이브러리 도입이 필요해지면 기존 위임 정책에 따라 사용자 승인을 받은 뒤 의존성/CI에 연결합니다. 승인 전에는 수집·표 선정·금액 검증 경로를 먼저 검증하며 완료 처리하지 않습니다.
