# 저장 수집 자료의 조회 실행

상태: 이슈 #108의 개발자 실행 경로입니다. 기존 수집 산출물과 [최신 현금 선택](latest-cash-source.md)을 연결하며 최종 비전공자용 입력 형식을 정하는 문서가 아닙니다.

## 입력과 책임

- 한 법인의 filing_history 수집 폴더와 annual/exact_receipts 원문 수집 폴더들을 명시합니다. 전체 유형 목록의 원시 응답·해시·파라미터·시각을 재검사하고, 원문 ZIP/모든 멤버/본문의 선언 해시·크기를 대조합니다.
- 원문은 요청 법인 및 이력의 정기보고서와 정확히 대응해야 합니다. 누락·추가·중복·다른 법인·해시 불일치를 임의로 무시하지 않습니다. 현재 개발자 경로는 단일 법인 수집 묶음입니다.
- 기존 요청 필드(모드·최대 경과 개월·선택 기준일·법인 코드·명시적 재무 범위·최소 원화 금액)와 시간대 있는 실행 시각을 받습니다. 임의 기본 시점/한도/금액은 없습니다.
- 본문 HTML의 접수번호·파일·실제 관측 시각을 명시합니다. 정정을 적용하려면 기존 CorrectionPair/CorrectionWebInputs에 대응하는 원시 파일과 메타데이터도 받습니다. 성공 상태나 준비된 금액을 입력받지 않습니다.

수집 폴더 내 파일 경로는 그 폴더를 벗어날 수 없습니다. JSON/응답/원문/웹의 기존 크기 제한을 유지하며 인증키는 읽거나 필요로 하지 않습니다. 수집 기록의 items/complete만 믿지 않고 원시 응답으로 다시 만든 목록을 사용합니다.

## 실행·출력

개발자 CLI는 저장 파일만 읽습니다. 새 API/웹 요청이나 대규모 조사는 수행하지 않습니다. 선택과 보류는 기존 query_latest_cash에 맡기고 별도 판정 기준을 만들지 않습니다. 선택 금액이 있으면 기존 지정 문서 엑셀 작성기로 연결하며 범위·요청/실제 날짜·원문 숫자/단위·실패와 검증 기록을 JSON에 남깁니다.

저장한 재무상태표 HTML도 제공하면 기존 링크 대조를 실행합니다. 없거나 대조에 실패하면 일반 공시 링크·표 바로가기 미확인 메모를 유지합니다. 금액을 0이나 미충족으로 바꾸지 않습니다. 출력 상단에는 지정 이력 내 최신 선택·개발용(전수 미완료)을 표시합니다. 기존 단일 공시 작성기의 기본 표시는 유지하고 새 CLI가 검증한 범위를 명시적으로 전달합니다. 제품 전수 결과로 표시하지 않습니다. 현금 미선정은 법인 금액 행을 만들지 않고 JSON에 사유를 남깁니다.

원문 영구 저장·자동 삭제·보관 기간·공유 저장소·전수 API 예산·최종 사용자 템플릿은 이 실행 경로가 결정하지 않습니다. 생성 결과는 Git 자동 커밋/푸시 대상이 아닙니다.

## 검증 기준

기존 실제 개발용 및 추가 법인 평가의 날짜·접수번호·원화 금액을 재현합니다. 테스트 정답을 실행 결과에서 새로 만들지 않습니다. 잘못된 경로/해시·중복/누락·다른 법인·일관되지 않은 목록 선언·미지원 상태는 성공 금액으로 바뀌면 안 됩니다. CLI를 통해 JSON·엑셀까지 재현하고 네트워크를 호출하지 않는지도 검사합니다.

## 개발자 명령

실행 진입점은 src/dartness/cash_bundle_runner.py이고 파일 검증은 src/dartness/collection_bundle.py입니다. 아래는 이미 받은 동진쎄미켐 자료의 **고정 시점 재현 예시**입니다. 입력 폴더는 [추가 법인 평가](../evaluations/latest-cash-dongjin-2026.md)의 수집 산출물 구조를 그대로 사용하며 최종 사용자에게 이 명령을 입력하도록 정한 것은 아닙니다.

```bash
PYTHONPATH=src python -m dartness.cash_bundle_runner \
  --history-dir work/dongjin/history \
  --source-dir work/dongjin/annual \
  --source-dir work/dongjin/interims \
  --source-dir work/dongjin/latest \
  --corp-code 00118804 --mode latest --max-age-months 12 \
  --basis separate --minimum-krw 50000000000 \
  --checked-at 2026-11-26T02:00:00+00:00 \
  --body 20261116000630 work/dongjin/latest/viewer.html 2026-11-26T01:29:41.764702+00:00 \
  --table-section work/dongjin/table-1.html \
  --output work/dongjin/replay/latest.json
```

기준일 지정은 --mode as_of --as-of 2025-12-31 --max-age-months 0처럼 명시합니다. 기존 날짜 계약대로 모드/개월 수를 임의 선택하지 않습니다. --body는 접수번호·HTML 경로·실제 관측 시각 세 인자이며 여러 번 제공할 수 있습니다. --table-section이 없거나 대조하지 못하면 일반 공시 링크와 미확인 메모를 유지합니다. 모든 읽기는 로컬 파일이며 CLI가 URL을 내려받지 않습니다.

### 정정 근거 파일

--correction-input에 아래 JSON 파일을 제공할 수 있습니다. 경로는 이 파일의 폴더 안에 있어야 하고 원시 HTML을 읽습니다. 준비한 성공 상태나 테스트 expected 값은 받지 않습니다. 실제 관계/정정표/금액 대조는 기존 정정 바인딩에 맡깁니다.

```json
{
  "original_receipt": "20260318001192",
  "correction_receipt": "20260602000456",
  "original_main": "original.html",
  "correction_main": "correction.html",
  "errata_html": "errata.html",
  "errata_url": "https://dart.fss.or.kr/report/viewer.do?rcpNo=20260602000456&dcmNo=11416776&eleId=1&offset=1015&length=3210&dtd=dart4.xsd",
  "observed_at": "2026-11-23T05:35:05.627459+00:00"
}
```

이 예시는 기존 개발용 관측의 시각/주소입니다. 현재 관측으로 바꾸어 표시하지 않습니다. 사용할 본문 관측과 공시 이력은 실행 시점 계약을 별도로 통과해야 합니다.

## 실패와 파일 보호

- JSON 입력은 1MiB, 목록 응답/ZIP은 32MiB, 웹 파일은 2MiB까지 읽습니다. ZIP의 기존 100개 멤버/128MiB 압축 해제 제한도 유지합니다.
- 출력 JSON이나 같은 이름의 XLSX가 이미 있으면 실행 전에 거절합니다. 기존 파일을 삭제하거나 덮어쓰지 않습니다.
- 로딩/선정 실패는 성공 금액·선정 법인 없이 확인 필요 JSON과 비정상 종료 코드로 기록합니다. 확인 필요일 때 XLSX를 새로 만들지 않습니다. 유효한 값의 조건 미충족은 정상 조회이며 기존 작성기의 빈 결과 안내를 사용합니다.
- JSON 저장 뒤 엑셀 작성이 실패할 수 있습니다. 비정상 종료로 알리며 성공한 파일 쌍으로 보고하지 않습니다. JSON은 남을 수 있습니다. 실제 데스크톱 Excel 렌더링 검증은 아닙니다.
- JSON의 input_locations는 내부 재현용 입력 경로입니다. 내부 결과를 Git에 자동 업로드하지 않으며 외부 공유 전 불필요한 내부 경로를 제거해야 합니다.

## 실행 확인

기존 추가 법인 평가 자료로 최신·2025말 지정 명령을 각각 실행했습니다. 최신은 2026-09-30의 166,741,090,356원, 2025말 지정은 최근 분기의 비교열 119,946,105,819원을 선택했고 JSON/엑셀 숫자·검증된 표 구간 링크가 같았습니다. 이는 **이미 평가한 자료의 CLI 재현**이며 새 독립 평가 건수에 더하지 않습니다.

tests/test_collection_bundle.py는 기존 수집기의 고정 응답 산출물과 합성 금액으로 로더·명령·JSON/엑셀을 연결합니다. 원시 응답과 요약 충돌, 경로 이탈, ZIP/멤버/본문 해시·크기, 중복·미완료 수집, 기존 파일 보호, 네트워크 미호출을 검사하며 기존 금액 정답은 변경하지 않습니다.
