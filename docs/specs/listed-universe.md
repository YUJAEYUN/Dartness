# 실행일 현재 상장법인과 공시 수집 연결

상태: 2026-11-25 합의한 코스피·코스닥·코넥스 모집단을 공식 OpenDART 자료로 관측하는 첫 연결입니다. 현재 상장법인 대상이며 지정한 과거 재무 기준일의 상장명부를 복원하지 않습니다.

## 공식 출처와 모집단 구성

[고유번호 가이드](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019018)는 corpCode.xml의 종목코드를 상장회사 정보로 설명합니다. [기업개황 가이드](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019002)의 company.json 법인구분 Y·K·N으로 현재 시장을 확인하고 E는 기타법인으로 제외합니다. 과거 공시의 시장 구분이나 최근 공시 유무로 모집단을 만들지 않습니다. 새 외부 래퍼·KRX 연동은 도입하지 않습니다.

실행 때 등록 ZIP을 새로 받아 종목코드가 있는 법인을 후보로 만듭니다. 같은 법인코드의 여러 종목코드는 묶어 기업개황을 한 번 확인합니다. 서로 다른 법인코드가 같은 종목코드를 소유하거나 기업개황의 현재 종목코드가 등록 자료와 맞지 않으면 임의로 합치지 않고 실패합니다. 법인 이름으로 매칭하지 않으며 표시 이름은 현재 기업개황에서 가져옵니다. 같은 법인의 등록 종목코드는 원본 식별 정보로 보존할 뿐 모두 현재 거래 가능한 종목이라고 주장하지 않습니다.

상장법인마다 기업개황 요청이 추가됩니다. 동시 호출·자동 재시도·캐시는 추가하지 않고 등록파일·기업개황·공시 페이지에 하나의 명시적 최대 요청 예산을 적용합니다. 예산 부족·일부 법인 확인 실패를 제외 후 성공으로 바꾸지 않습니다. 세 시장 중 하나가 누락되면 불완전 모집단으로 실패합니다. 이 확인만으로 실제 모든 상장법인이 빠짐없이 포함됐다고 보증하지는 않습니다.

## 관측 시각과 출처

QueryRun.execution_date는 한국 실행일입니다. 실제 관측 시작/끝 시각이 시간대를 포함하고 그 날짜와 같아야 합니다. 자정 경계를 넘거나 시각이 거꾸로 가면 같은 날짜의 현재 명부로 완료하지 않습니다. 기본 시계는 현재 UTC 시각이며 테스트에서만 합성 시계를 주입합니다.

모집단은 관측 구간·등록 ZIP SHA-256·기업개황 응답 SHA-256·공식 endpoint·법인/종목 식별자·등록파일의 modify_date·제외한 기타법인 코드를 보존합니다. modify_date는 기업개황 정보의 변경일이지 상장일이나 모집단 기준일이 아닙니다. API 키·연락처·대표자 등 불필요한 원문 필드는 결과에 보관하지 않습니다.

## 공시 목록 연결

제출일 검색 범위는 별도로 명시하고 종료일은 한국 실행일을 넘지 않습니다. 과거 재무 기준일 조회도 모집단은 실행일 현재 명부를 사용합니다. 현재 모집단의 공시를 과거 시장 변경 때문에 놓치지 않도록 list.json은 법인/시장 필터 없이 수집한 뒤 현재 법인코드로 연결합니다. 공시유형 필터는 전달할 수 있습니다. 전체 자료를 받으므로 비대상 공시도 호출 예산을 사용하며 제외 건수를 기록합니다.

등록 ZIP·기업개황으로 모집단을 관측한 뒤 남은 예산을 기존 공통 공시 목록 수집기에 전달합니다. 반환 목록은 모집단 법인의 공시만 담고, 공시가 없는 법인도 모집단과 별도 no_filings 항목에 남깁니다. 이는 해당 제출일 범위/공시유형에서 공시가 없다는 뜻이며 자산 미보유·현금 0·조건 미충족이 아닙니다.

중간 실패·등록/기업개황 충돌·공시 수집 오류·예산 초과·관측 날짜 변경이면 전체 결과를 반환하지 않습니다. 원문·정정 적용·실제 재무 기준일·자산/금액 조건·엑셀은 아직 연결하지 않았습니다.

## 완전성·검증 한계

이름이 아니라 공식 법인코드로 연결하고 세 시장 및 응답 일관성을 검사하지만, OpenDART 등록정보의 누락·갱신 지연·기업개황의 비원자적 관측을 없애지 못합니다. 등록파일에서 종목코드가 빠진 신규 상장법인을 발견하거나 독립 KRX 자료로 수량을 대조하는 기능은 없습니다. 결과는 실행일에 OpenDART가 제공한 등록정보 관측이며 완전한 거래소 명부를 독립 검증한 결과가 아닙니다. 과거 명부나 오래된 캐시를 현재 명부로 표시하지 않습니다.

단위/통합 테스트는 공식 필드 계약을 따른 합성 ZIP·JSON입니다. 새 연결로 실제 API 전수 호출·실제 상장법인 수·재무 추출 정답 검증을 완료했다고 표현하지 않습니다. 기존 평가용 수집기·기존 정답·위임 정책은 유지합니다.
