# 결과물 예시

!!! warning "양식 검토용 가상 데이터"
    아래 법인·금액은 실제 조회 결과가 아닙니다. 링크는 예시에서 비활성 표기합니다. 최종 열과 글자 크기는 사용자와 다듬습니다.

## 현금및현금성자산 500억원 이상

법인 자체 기준(별도·개별). 표시 금액의 단위: 억원. 아래는 요청 기준일 2026-09-30, 최대 경과 기간 6개월을 사용자가 입력한 가상 예시이며 이 기간은 기본값이 아닙니다. 두 법인은 조건 충족 금액을 원문에서 확인했다고 가정합니다.

2026-11-25 사용자 요청으로 기본 표를 법인명·금액·조회 기준 중심으로 간결하게 합니다. 아래는 가상 데이터입니다. 실제 파일에서는 법인명을 누르면 확인된 근거 표 구간이 열리고 금액 메모에서 원문 숫자·단위·정확한 원화 값·공시일을 볼 수 있습니다. 해시·추출 로그는 내부 기록에 보존합니다.

| 법인명 | 현금및현금성자산(억원) | 조회 기준 |
|---|---:|---|
| 가람전자 | **560.00** | 2026.09.30 · 별도 |
| 나래산업 | **820.00** | 2026.06.30 · 별도 · 이전 자료 |

공통 요청 기준일 2026.09.30은 파일 상단에, 실제 자료 날짜는 각 행의 조회 기준에 표시합니다. 이전 자료 여부·연결/별도·통화가 달라지는 정보를 숨기지 않습니다. 억 단위 표시는 읽기 위한 형식이며 조건은 정확한 원화 금액으로 판정합니다. 내부 검증 기록을 기본 표에서 덜어내는 것이 검증을 생략한다는 뜻은 아닙니다.

확인 불가 법인은 기본 결과에서 제외합니다. 검토 내역 포함을 선택하면 별도 시트에 법인·이유·확인 경로를 추가합니다. 예: 다온기업은 허용 범위 내 자료 기준일을 확인하지 못해 금액을 확정하지 않습니다. 옵션과 무관하게 내부 기록은 보존합니다. 확정된 정책은 [공통 계약](common-query-contract.md)을 따릅니다.

## 표시 원칙

필수 단위·기준일은 숨기지 않습니다. 긴 원문·세부내역을 메모나 상세 시트로 옮기는 방식은 후보입니다. 메모만으로는 인쇄·미리보기에서 누락될 수 있습니다. 실제 엑셀에서 숫자는 정렬과 계산이 가능한 숫자 셀로 유지할 예정입니다.

2026-11-25 사용자 서식 요청: 제목·머리글·본문·링크를 모두 왼쪽 정렬·10포인트로 통일하고 Excel 눈금선을 표시합니다. 셀 내용·금액·근거 링크·메모를 삭제하지 않습니다.

사용자의 후속 참고 양식에 맞춰 흰 바탕·상단 조회 정보 한 줄·2행 굵은 머리글·3행부터 데이터·기본 행 높이·A3 틀 고정/필터로 정리합니다. 왼쪽 정렬·10포인트·눈금선·세 열과 근거는 유지합니다. 참고 파일의 회사/팀/분류 내용은 사용하지 않습니다.

근거 표 바로가기는 DART 문서별 목차와 실제 표의 날짜·단위·금액을 대조한 경우에 제공합니다. 현재 현금 실행은 재무상태표 구간으로 직접 연결하며 특정 행 스크롤은 보장하지 않습니다. 확인하지 못한 경우에는 공시 전체 링크를 유지하고 금액 메모에 `표 바로가기 미확인`을 표시합니다. 내부 JSON에는 원래 공시 URL과 직접 링크·응답 해시·실패 이유를 구분합니다. 자세한 동작은 [지정 공시 실행](cash-report-slice.md#table-link)을 따릅니다.
