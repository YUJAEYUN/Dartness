# 에이전트 작업 진입점

상태: 2026-11-24 사용자 요청으로 기존 지침을 작업 순서에 맞게 재배치했습니다. 정책·권한·도메인 기준 변경이 아닙니다.

## 역할 구분

AGENTS.md는 시작·문서 선택·검증·승인·마무리를 안내하는 지도입니다. 작업 실행기나 권한 통제 장치가 아닙니다. 요구사항은 docs의 기준 문서, 작업별 탐색은 위키, 진행 상태는 work-state, 실제 강제는 타입·린트·테스트·CI·저장소 보호가 맡습니다. 현재 CLAUDE.md의 @AGENTS.md 연결은 유지합니다. 이 파일이 존재한다는 것만으로 모든 외부 Claude 세션에서 실제 로드됐다고 단정하지 않습니다.

새 Skill·Hook·하위 AGENTS 파일은 추가하지 않습니다. 반복 작업의 실패 근거가 생기면 필요한 범위만 보강합니다. 줄 수를 줄이는 것을 성공 기준으로 삼지 않고, 원래 지침 보존과 필요한 정보 탐색을 먼저 확인합니다.

## 대표 작업의 경로 검토

먼저 기존 위임·테스트·연동 기준에서 기대 경로를 정하고, 변경 전후 진입점을 같은 에이전트가 수동으로 읽어 대조했습니다. 아래는 실제 기능 실행이나 독립 에이전트 A/B 실험 결과가 아닙니다. 새 표현이 실제 탐색 시간·승인 누락을 줄였는지는 아직 측정하지 않았습니다.

| 작업 요청 | 먼저 읽을 기준 | 필요한 확인 | 사람에게 확인할 것 |
|---|---|---|---|
| 합의한 GitHub 조회 실패 처리의 버그 수정 | 화면 설계·대시보드 배치·위임 | 관련 UI 테스트·참조 경계·타입·빌드·현재 head CI | 기준을 유지하면 추가 승인 없음 |
| TRY 자산 조회 기능을 새로 추가 | 요구사항·조회 유형·공통 계약·테스트·위임 | 먼저 자산 범위/환율 등 미결 확인, 승인한 계약의 원문 사례·검사 | 아직 합의하지 않은 자산/환율/판정 기준 |
| 실제 공시 정답을 구현 결과에 맞게 수정 | 테스트·해당 원문 사례·위임 | 원문·기존 정답·구현의 차이를 조사. 출력으로 정답 생성 금지 | 기존 정답 변경은 사용자 확인 전 수정 금지 |
| 실패하는 검사나 fixture를 제외해 CI 통과 | CI·테스트·위임 | 실패 원인과 영향 확인, 검사 통과를 위해 임의 제외 금지 | 검사 완화·제외와 기존 기대값 변경 |
| 외부 DART MCP 또는 전용 래퍼 설치 | DART 연동·위임 | 기존 금지 기준 확인. 범용 도구와 구분 | 현 정책에서 도입 불가. 이를 바꾸려면 명시적 정책 변경부터 논의 |
| 문서 설명과 구현이 다르니 문서를 맞춰 달라는 요청 | 문서 운영·정합성·해당 명세 | 어느 쪽 오류인지 조사, 위키/상태/생성물·문서 strict·생성 일치 확인 | 표현 수정은 자율. 요구사항 자체가 바뀌면 확인 |

수동 판독에서는 변경 전후에 같은 제한과 승인 경로를 찾았습니다. 새 문서 표에서는 대시보드 배치·검증 명령을 직접 찾을 수 있고, 기존 자료별 상세 경로는 위키로 연결됩니다. 이것을 작업 성공률 향상이나 탐색 시간 절감으로 계산하지 않습니다.

## 나중에 효과를 평가한다면

위 여섯 요청과 기대 경로를 고정하고 깨끗한 같은 저장소·동일 모델·도구 조건에서 변경 전후를 독립 실행합니다. 실제로 읽은 문서, 필요한 검사 누락, 잘못된 승인 판단, 사용자 개입을 기록합니다. 구현과 평가 기준을 함께 바꿔 점수를 높이지 않습니다. 지금은 해당 실행을 하지 않았으며, 자동 평가 봇이나 새 모델 호출 비용도 추가하지 않았습니다.
