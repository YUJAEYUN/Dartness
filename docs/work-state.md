## 다음에 함께 정할 것

화면을 보고 읽기 쉬운지 확인합니다. 현금 조회는 별도·개별을 기본으로, 연결은 선택하기로 확정했습니다. 확인 불가는 이유를 기록하고 0원·연결 금액으로 대체하지 않습니다. [계약 초안](cash-query-contract.md)을 바탕으로 실행 스키마·고정 검증 사례를 준비하는 것이 다음 기능 작업입니다. 합의한 작은 금액 차이 표시 기준은 유지하며 자동 오차 판정은 아직 구현하지 않았습니다.
