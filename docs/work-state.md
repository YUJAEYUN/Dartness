- 관리 화면의 GitHub 최신 조회와 검증된 저장본 대체 배포를 완료했습니다(이슈 #69). 운영 결과는 해당 이슈에서 확인합니다.

- 문서를 specs·design·guides로 분류하고 링크·생성기·검사 경로를 함께 갱신했습니다(이슈 #74). [배치 기준](design/documentation.md)을 따릅니다.

- 정정 연결의 공식 API 정보와 실제 보고서 한 쌍을 [조사](design/correction-linking.md)했습니다. 전체 본문 PDF·원문 XBRL을 확보한 [개발용 정답 사례](cases/hd-construction-correction.md)에서 현재기 현금 두 셀을 대조했습니다. 동일 보고서 연결과 항목 영향은 분리하며 자동 연결·적용은 미구현입니다. 이 작업은 클로드의 수집·파서 이슈와 분리합니다.

- 공통 조회·시점·출력 정책을 [계약 초안](specs/common-query-contract.md)과 대시보드에 반영했습니다. 모집단은 실행일 현재 세 시장 상장법인입니다. 최신 자료/기준일 지정·개월 선택지·달력 계산·최신 정정·출력 옵션은 합의했고 공통 입력·날짜 계약은 구현했습니다. 수집·정정·추출·출력을 연결한 실행 엔진은 아직 없습니다.
- 이슈 #32는 2026-11-24 사용자 요청으로 명세 작업 완료 종료했습니다. 실행 가능한 라우터나 현금 외 추출 모듈은 아직 없습니다.
- 현금 표 추출 평가(이슈 #31, 종료): 첫 평가 6곳·11건은 추출기를 고친 뒤 개발용입니다. 처음 보는 5개 법인 9건에서 틀린 금액 0, 8건 정답(금융업 6건은 정답대로 확인 필요). 그 뒤 계정명 앞 목차 기호를 떼고 비교하게 해(이슈 #56) 대한약품 1건도 개발용이 됐습니다. [첫 평가](evaluations/cash-table-dart-2025.md), [두 번째 평가](evaluations/cash-table-dart-2025-second.md)
- 12월이 아닌 결산 법인 평가(이슈 #58): 수집기가 기업개황의 결산월로 보고서를 찾습니다. 3곳 5건(신영증권, SBI핀테크솔루션즈, JTC)에서 틀린 금액 0, 모두 정답대로 확인 필요였습니다. [세 번째 평가](evaluations/cash-table-dart-2025-third.md)

## 다음에 정할 것

- 실행일 현재 상장법인 모집단의 공식 원천과 목록 수집 연결 범위를 정합니다. 수집한 목록을 재무 기준일 후보나 조건 충족 결과로 취급하지 않습니다.

- 대시보드는 기능별 폴더와 참조 경계를 [배치 기준](design/dashboard-structure.md)에 따라 정리했습니다(이슈 #76). Python 모듈은 확장 필요가 나타날 때 세분화합니다.
- AGENTS.md를 작업 진입점으로 재배치하고 기존 지침 보존·여섯 작업 경로를 [대조](design/agent-entrypoint.md)했습니다(이슈 #78). 위임 권한은 유지하며 독립 에이전트 A/B 효과는 미측정입니다.

- 작업 결과 기록을 실제 작업에서 사용하고, 누락되거나 반복되는 실패가 생기면 필요한 항목·검사를 보강합니다. 아직 성공률·개입 시간·자동 승인 효과를 측정했다고 해석하지 않습니다.

- 확보한 원본·정정 개발용 정답을 바탕으로 명시적 원본 관계·항목 적용 근거를 검증하는 계약을 구현합니다. 전체 본문 PDF·XBRL ZIP과 OpenDART 제출서류 XML ZIP의 형식·해시는 구분합니다.
- 유형별 자산·금액 조건과 원문 후보 생성 방식을 정한 뒤 공시 후보 계약을 수집·추출에 연결합니다. 키가 같다는 검사는 원문 의미 판정이 아닙니다.
- 유형별 자산 범위·환율·평가 기준·사건·당사자와 금액 비교 정책은 미결입니다.
- 금융업 현금 기준(이슈 #57, 보류): 지금은 재무상태표에 현금및현금성자산 행이 없으면 확인 필요입니다. 필요해지면 현금흐름표 기말 현금을 검토합니다.
- 외화(엔화 등) 공시 법인의 현금 조회 방식과, 원화로 공시하는 12월이 아닌 결산 비금융 법인의 값 추출 확인은 미결로 둡니다(2026-11-23 사용자 결정, 이슈 #67). 문제가 생기면 그때 다룹니다.

## 알려진 한계

- 전체 보고서의 절 자동 선정과 범용 의미 추출, 전체 법인 수집, 캐시, 환율, 합계 자동 판정, 엑셀 생성은 아직 없습니다.
- 병합 범위는 작업 중인 에이전트가 판단합니다. 상시 실행 에이전트나 자동 병합 봇은 없습니다.
- 자동 검사는 문서에 적힌 경로·규칙 ID의 존재와 이 문서의 형식만 확인합니다. 설명과 구현의 의미가 맞는지는 [정합성 검토](consistency.md)로 사람이나 에이전트가 확인합니다.
- 관리 화면의 모바일·클릭 상세 검토는 사용자와 합의해 보류했습니다.
