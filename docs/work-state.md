# 다음 작업

## 현재 작업

문서·위키·코드의 정합성을 확인하며 개발하는 흐름과 짧은 이슈·PR·설계 결정 템플릿을 추가합니다. 이 변경은 작업 브랜치와 PR로 검토하며 병합 전에는 제안 변경입니다.

## 이미 있는 환경

문서 사이트·개념 흐름도·가상 결과 예시·위키 진입점·개발 안내·문서 빌드 CI·수동 게시 워크플로가 있습니다. 주간 예약 검사는 문서 빌드이며 LLM 의미 검토가 아닙니다.

## 이번 변경

[작업 흐름](development-workflow.md), [정합성 기록](consistency.md), 템플릿을 연결합니다. AMOUNT-001을 첫 추적 규칙으로 삼되 구현·테스트는 미구현으로 표시합니다. 검증 명령과 실제 결과·기준 커밋은 해당 PR에 기록합니다.

## 다음 행동

실제 공시 한 건에서 금액·기간·단위를 어떻게 추출하고 검증할지 추천안을 하나씩 논의합니다. 단위 불명확 사례와 정상 사례의 기대 결과를 정한 후 최소 구현을 시작합니다. 아직 조회 엔진 기술·전체 스키마·패키지 구조를 확정하지 않습니다.

## 미결과 한계

기본 시점, 합계 오차 정책, 최종 엑셀 열·메모, 문서 대체 경로는 미결입니다. DART 조회 코드·실제 엑셀 생성기·정합성 자동 의미 평가기는 없습니다. 브랜치 보호와 필수 CI 설정은 문서만으로 강제되지 않습니다.
