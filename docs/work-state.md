# 다음 작업

## 현재 목표

docs 원본을 사람이 읽기 쉬운 문서 사이트로 제공하고, 에이전트가 같은 기준으로 작업을 이어가게 합니다.

## 완료 범위

문서 사이트 설정, 개념 흐름도, 가상 결과 예시, 위키 진입점, 개발 에이전트 안내, 문서 빌드 CI와 수동 게시 워크플로를 추가했습니다. 최종 검증 결과는 변경의 커밋·PR 기록에서 확인합니다.

## 다음에 함께 결정할 것

문서 사이트의 구성과 결과물 예시를 먼저 확인합니다. 이후 실제 공시 한 건으로 추출·검증 흐름을 구체화합니다. 기본 시점·합계 오차 정책·최종 열과 데이터 계약은 아직 미결입니다.

## 구현 상태

DART 조회 코드·확정 스키마·실제 엑셀 생성기는 없습니다. 초기 기술 추천안은 채택된 아키텍처가 아닙니다. 예약 문서 검사는 기계적 검사이며 LLM 기반 정합성 검토가 아닙니다.
