# 다음 작업

## 완료한 작업

PR #1·#4·#6·#8이 main에 병합됐습니다. 문서 사이트·위키·개발 절차·테스트 작성 기준과 금액 단위 변환 코드가 있습니다. 사용자가 build·code-quality를 필수 검사로 등록했다고 확인했습니다.

헬릭스미스 실제 사례에서 주석 내부 합계와 재무상태표 대조를 구분했습니다. 사용자는 표시 단위로 설명 가능한 작은 차이를 기본 표에서 경고하지 않고 내부 기록에 보존하는 기준에 동의했습니다. 이번 53원 차이는 경고 생략 사례이며, 공통 고정 오차나 반올림 방식을 정한 것은 아닙니다.

## 현재 작업

이슈 #9·PR #10의 [실제 DART 수집](dart-live-check.md)은 수동 실행 44653561475에서 성공했습니다. 접수번호 20260320001142의 ZIP·XML 3개와 문서 해시를 확인했습니다. 외부 DART MCP·스킬·전용 래퍼 없이 공식 API를 직접 사용합니다.

PR #8 병합 후 최신 main을 PR #10에 반영하며 공통 안내·위키·작업 상태·문서 탐색 설정의 충돌을 정리했습니다. 코드·문서 검사를 다시 확인하고 사용자 승인 후 병합합니다. 키 등록이나 새 필수 검사 추가는 필요하지 않습니다.

## 다음에 함께 정할 것

법인 자체(별도·개별)와 그룹 전체(연결) 중 조회 기본 기준을 정합니다. 이후 수집한 원문에서 기간·단위·금액·근거 위치를 읽는 입력·출력 계약과 실패 사례를 다음 이슈로 구현합니다. 별도 검증용 다른 법인·서식도 선정해야 합니다.

## 아직 없는 기능

전체 법인 수집·캐시·원문 의미 추출·환율·합계 판정·엑셀 생성은 없습니다. KIND와 DART 자료의 전체 내용 일치·정정 관계도 아직 확인하지 않았습니다. 수집 성공과 재무정보 정답 검증은 구분합니다.
