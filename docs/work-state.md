## 진행 중인 작업

- 공통 조회·시점·출력 정책의 사용자 선택을 [계약 초안](common-query-contract.md)과 대시보드에 반영합니다. 전수 모집단은 실행일 현재 세 시장 상장법인, 이전 자료는 사용자 한도 내 선택·표시, 최신 정정·출력 옵션을 합의했습니다. 실행 엔진은 아직 없습니다.
- 이슈 #32는 열어 둔 상태를 유지합니다. 최신 main의 평가용 공시 수집·변이 테스트는 보존하며 새 운영 선택 정책과 구분합니다.

## 다음에 정할 것

- 최대 경과 기간의 입력 단위·경계 계산을 정하고 실행 가능한 공통 요청·선택 결과 계약을 만듭니다.
- 유형별 자산 범위·환율·평가 기준·사건·당사자와 금액 비교 정책은 미결입니다.
- 평가용 수집 결과의 원문 대조와 실제·별도 검증용 사례를 준비합니다. 준비 워크플로가 곧 정확도 검증 완료를 뜻하지 않습니다.

## 알려진 한계

- 전체 보고서의 절 자동 선정과 범용 의미 추출, 전체 법인 수집, 캐시, 환율, 합계 자동 판정, 엑셀 생성은 아직 없습니다.
- 병합 범위는 작업 중인 에이전트가 판단합니다. 상시 실행 에이전트나 자동 병합 봇은 없습니다.
- 자동 검사는 문서에 적힌 경로·규칙 ID의 존재와 이 문서의 형식만 확인합니다. 설명과 구현의 의미가 맞는지는 [정합성 검토](consistency.md)로 사람이나 에이전트가 확인합니다.
- 관리 화면의 모바일·클릭 상세 검토는 사용자와 합의해 보류했습니다.
