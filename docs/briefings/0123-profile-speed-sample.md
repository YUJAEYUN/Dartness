# 공개 20개 법인에서 기업개황 처리 속도 비교

## 한 줄 요약

기존 소수 비교를 20개 법인·최대 80회로 확대해 운영 수집 개선의 근거를 확인합니다.

## 지도에서의 위치

```mermaid
flowchart LR
    A[현재 상장 명부 수집] --> B[공시 원문 수집]
    B --> F[현금 조건 조회]
    F --> I[엑셀 출력]
    classDef changed fill:#dbeafe,stroke:#2563eb,stroke-width:3px
    class A changed
```

## 무엇이 달라졌나

기존 수동 비교에 profile_speed_probe_20 모드를 추가합니다. 공개 20개 법인에 순차·동시 2개 처리를 각각 두 번 비교하고 두 번째 회차는 순서를 뒤집습니다. 총 80회·시작 간격 0.5초·오류 중단·재시도 없음·240초 제한을 유지합니다. 기본 두 법인 모드는 바꾸지 않습니다.

## 누가 무엇을 정했나

사용자는 더 큰 표본의 안정성 확인을 진행하기로 했습니다. 과거 공개 고유번호 파일은 표본 식별자 출처로만 사용하며 현재 명부로 대신 쓰지 않습니다. 운영 수집기·당일 확인·기존 정답·판정 기준·권한·의존성은 유지합니다.

## 확인해 주세요

이 실험 범위에서 추가 사용자 판단은 없습니다. 운영 적용이나 전수 실행은 이번 실험 성공과 구분합니다.

## 확인한 것과 못 한 것

실행 전 고정 응답으로 80회 상한·20개 표본·회차 순서·제한 오류 중단을 검사합니다. 실제 80회 모두 성공했고 평균 순차 16.680초·동시 10.571초로 이 표본에서 약 37% 줄었습니다. 법인별 네 번의 응답 해시가 같고 제한/네트워크 오류는 없었습니다. 전수 속도로 환산하지 않습니다. 상장시장 전체의 무작위 표본이 아니며 금융업 현금 기준이나 전수 금액·명부 정확성을 평가하지 않습니다. 현재 키의 잔여 일일 한도는 확인하지 않았습니다.
