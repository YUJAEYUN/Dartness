# 정정 전체 자료와 개발용 정답 확보

## 한 줄 요약

원본·정정의 전체 PDF와 원문 XBRL을 확보하고, 같은 기준일의 연결·별도 현금 두 셀을 대조해 정답을 고정했습니다. 기존 선택기는 두 버전을 임의로 고르지 않고 보류합니다.

## 지도에서의 위치

원문 수집(C)과 계약 검증(F)에 사용할 개발용 증거를 준비했습니다. 운영 코드나 처리 단계의 구현 상태는 바뀌지 않았습니다. 자동 원본 연결·정정 적용은 아직 없습니다.

## 무엇이 달라졌나

| 전 | 후 |
|---|---|
| 웹 뷰어·선정 구간만 관찰 | 전체 본문 PDF와 재무정보 XBRL ZIP 각 두 버전 보존 |
| 현금 변경/불변 미확인 | 2025-12-31 연결·별도 두 재무상태표 셀은 같음을 대조 |
| 후속 테스트는 계획 | 원문 기반 정답과 기존 보류 동작을 검사하는 신규 14개 테스트 |

연결은 337,873,166천원, 별도는 69,787,650천원으로 두 버전에서 같습니다. 전체 재무정보가 같다는 뜻은 아닙니다. 같은 현금 태그도 문서당 14개라서 기간·차원·정밀도를 구분해야 합니다.

## 누가 무엇을 정했나

**사용자가 정한 것**

- 원본·정정 전체 원문을 확보하고 연결기의 개발용 정답 사례를 먼저 준비합니다.
- 추정하지 않고 실제 단위·기간·재무 범위·근거를 보존합니다.
- 이슈를 나눠 클로드의 수집·현금 파서 작업과 분리합니다.

**작업 중 에이전트가 정한 것**

- 공식 공개 다운로드의 PDF·원문 XBRL을 사용했습니다. 본문이 빈 응답은 성공으로 쓰지 않았고 공개 화면의 세션·요청 헤더로 다시 받았습니다.
- 네 전체 파일은 별도 데이터 브랜치의 고정 커밋에, main에는 작은 증거·정답만 저장했습니다.
- 원본 바이트에서 뽑아 조립한 XML과 PDF 변환 텍스트는 파생 자료로 표시했습니다. 전체 문서 해시와 발췌 해시를 구분합니다.
- 키·시크릿·워크플로·권한·기존 수집기·파서·정답은 변경하지 않았습니다.

## 확인해 주세요

이번 사례 준비를 위해 추가로 판단할 것은 없습니다. 다음 구현은 명시적 원본 관계·항목 적용 근거를 검증하는 계약입니다. 여러 정정 차수·철회·첨부정정은 아직 미결입니다.

## 확인한 것과 못 한 것

| 확인한 것 | 못 한 것 |
|---|---|
| 전체 PDF 두 건·XBRL ZIP 두 건의 형식·크기·해시·ZIP CRC | OpenDART document.xml 제출서류 ZIP 및 모든 첨부의 완전성 |
| 현재기 연결·별도 현금의 PDF 천원 행과 XBRL 문맥·KRW·값 | 전체 항목·주석의 의미 불변, 범용 XBRL 추출 |
| 신규 14개 포함 Python 465개·대시보드 40개, 문서·린트·타입·빌드 | 자동 원본 연결·정정본 선택·유형별 조건 비교 |

한 쌍을 읽고 만든 개발용 사례이며 독립 검증용 평가가 아닙니다. 현재 후보 선택기는 금액이 같다는 이유로 두 버전의 모호함을 건너뛰지 않습니다. CI·병합·배포 근거는 이슈·PR에 남깁니다.
