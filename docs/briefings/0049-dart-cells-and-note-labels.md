# DART 원문 표 칸과 주석 번호 읽기

## 한 줄 요약

현금 표 추출기가 DART 원문의 표 칸(TE 태그)과 "현금및현금성자산 (주4,29)" 같은 계정명을 읽게 됐습니다. 첫 평가에서 0건이던 DART 원문 추출이 11건 모두로 바뀌었고, 틀린 금액은 여전히 없습니다.

## 지도에서의 위치

```mermaid
flowchart LR
    C[원문 수집] --> D[현금 행·열 추출]
    D --> E[단위 정규화]
    classDef changed fill:#dbeafe,stroke:#2563eb,stroke-width:3px
    classDef same fill:#f9fafb,stroke:#d1d5db
    class D changed
    class C,E same
```

D 단계가 원문 수집(C)이 받아 오는 DART 원문 형식을 읽을 수 있게 됐습니다. 상태는 "일부" 그대로입니다. 고칠 때 본 사례로만 확인했기 때문입니다.

## 무엇이 달라졌나

| | 전 | 후 |
|---|---|---|
| DART 원문 11건 | 0건 추출 | 11건 모두 정답 |
| 표 칸 | TD 태그만 읽음 | TE 태그도 같은 방식으로 읽음 |
| 계정명 | "현금및현금성자산"만 인정 | "(주4,29)"처럼 주석 번호만 붙은 이름도 인정 |

"현금및현금성자산 등"처럼 다른 말이 붙은 이름은 여전히 현금 행으로 보지 않습니다.

## 누가 무엇을 정했나

**사용자가 정한 것**
- 첫 평가 결과를 보고 추출기를 고치기로 했습니다(2026-11-23).

**구현 중 에이전트가 정한 것**
- 인정하는 주석 번호 형식은 "주"와 숫자·쉼표만 든 괄호 하나입니다. 괄호가 앞에 붙거나 뒤에 다른 말이 더 있으면 인정하지 않습니다.
- 평가 11건을 개발용으로 바꾸고, 11건 모두 추출돼야 한다는 회귀 테스트를 추가했습니다.

## 확인해 주세요

없음. 고칠지는 이미 정했고, 새 검증용 평가 대상은 다음 작업에서 정합니다.

## 확인한 것과 못 한 것

| 확인한 것 | 못 한 것 |
|---|---|
| DART 원문 11건 정답, 틀린 금액 0건 | 처음 보는 법인에서의 정확도 |
| 비슷하지만 다른 계정명 4가지 거절 | 금융업, 12월이 아닌 결산, 분기보고서 서식 |
| 변이 테스트에서 새 코드의 변이 모두 잡힘 | 보고서 전체에서 구간 자동 찾기 |
