# 요청 날짜의 최신 유효 공시에서 현금 선택

## 한 줄 요약

같은 재무 날짜를 담은 여러 공시 중 검증된 최신 제출본을 사용합니다.

## 지도에서의 위치

```mermaid
flowchart LR
    B[이력과 실제 재무 날짜 확인] --> D[당기·비교열 현금 읽기]
    D --> F[최신 제출본과 정정 관계 검증]
    F --> H[선택 금액으로 조건 비교]
    classDef changed fill:#dbeafe,stroke:#2563eb,stroke-width:3px
    class B,D,F,H changed
```

## 무엇이 달라졌나

먼저 요청에 맞는 재무 날짜를 고르고, 해당 날짜를 담은 최신 공시를 검증합니다. 사업·반기·분기보고서의 당기/비교열을 구분합니다. 수집 목록의 원시 응답·파라미터·해시·페이지와 원문 식별을 다시 검사하고 선택한 본문의 관계를 이력과 대조합니다. 지원 사업보고서 정정 한 쌍은 기존 전체 XML/정정표/두 셀 대조를 재사용합니다.

## 누가 무엇을 정했나

사용자는 이미 합의한 최신 유효 공시 기준으로 진행하도록 재확인했습니다. 에이전트가 요청했던 금액 일치 시 묶기 제안은 철회했습니다. 금액이 같은지로 최신본을 고르지 않습니다. 기존 준비 입력용 후보 v1과 기대 정답은 유지하고 검증된 상위 실행을 추가했습니다.

## 확인해 주세요

새 결정 요청은 없습니다. 지정 이력 안의 지원 정기보고서 연결이며 전체 시장 전수·모든 정정 유형·독립 E2E 완료는 아닙니다. 같은 제출일의 순서 불명·미수집·읽기 실패·미지원 첨부/철회/다중 정정은 확인 필요로 남깁니다.

## 확인한 것과 못 한 것

실제 개발용 HD건설기계의 이력 50건·정기보고서 6개를 대조했습니다. 2025말 요청은 최근 분기의 2025-12-31 비교열 69,787,650,000원, 최신 요청은 같은 문서의 2026-09-30 당기열 134,070,870,000원입니다. 최신 유효 금액이 이전 공시와 다른 합성 사례에서도 최신 값을 고르는지 검사합니다. 한 법인의 이미 읽은 자료이며 독립 평가 성능으로 세지 않습니다. CI·배포 최종 근거는 이슈에 기록합니다.
