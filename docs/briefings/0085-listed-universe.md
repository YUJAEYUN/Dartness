# 실행일 상장법인과 공시 목록 연결

## 한 줄 요약

공식 OpenDART 등록파일·현재 기업개황으로 세 시장 상장법인을 관측하고 공통 공시 목록을 법인코드로 연결합니다.

## 지도에서의 위치

```mermaid
flowchart LR
    A[조회 조건 입력] --> B[법인·공시 찾기]
    B --> C[원문 수집]
    classDef changed fill:#dbeafe,stroke:#2563eb,stroke-width:3px
    class B changed
```

B 단계에서 실행일 모집단과 목록을 연결했습니다. 보고서 의미·정정 연결/선택과 실제 운영 전수 검증은 남아 있어 일부 상태를 유지합니다.

## 무엇이 달라졌나

고유번호 파일의 종목코드 후보를 기업개황의 현재 시장으로 확인하고 법인코드로 통합합니다. 원본 해시·관측 구간·변경일·기타법인 제외를 보존합니다. 공시는 과거 시장 필터로 제한하지 않고 현재 모집단 법인코드와 연결해 무공시 법인도 남깁니다. 등록·기업개황·페이지 요청은 하나의 예산 안에서 처리하며 중간 실패·날짜 변경은 전체 결과를 반환하지 않습니다.

## 누가 무엇을 정했나

**사용자가 정한 것**

- 조회 실행일 현재 코스피·코스닥·코넥스 상장법인 목록을 공통 수집기에 연결합니다.

**구현 중 에이전트가 정한 것**

- 별도 외부 서비스 대신 공식 corpCode.xml과 company.json을 조합했습니다. 종목코드가 있는 후보마다 기업개황 요청이 추가됩니다.
- 이름을 유사 매칭하지 않고 법인코드·종목 식별자를 대조합니다. 종목코드가 없는 등록 회사는 후보로 삼지 않으며 이 방식의 신규 상장 누락/지연 한계를 명시했습니다.
- 공통 수집은 명시적 실행 시각과 제출일 범위를 받아 조회 유형에 종속되지 않게 했습니다. 기존 QueryRun에서는 executed_at을 전달합니다.
- API가 제공한 현재 자료를 관측한 결과이며 독립 거래소 명부 검증으로 표현하지 않았습니다.

## 확인해 주세요

추가 결정은 없습니다. 실제 API 전수 검증·KRX 대조·정정/원문/금액/엑셀 연결은 이번 범위가 아닙니다. 실제 실행에서는 기업개황 확인 요청을 포함한 예산이 필요합니다.

## 확인한 것과 못 한 것

| 확인한 것 | 못 한 것 |
|---|---|
| 합성 ZIP/JSON의 시장·법인 통합·해시·실행일·공시 연결·무공시 보존 | 새 연결의 실제 상장법인 수와 전수 API 대조 |
| 프로필/등록 충돌·오류·예산·자정/시각 역행·부분 성공 방지 | 원천 등록정보의 갱신 지연·누락·비원자성 제거 |
| 현재 상장법인의 과거 다른 시장 공시도 연결, 기존 정답 유지 | 역사적 상장명부·자산 조건·금액·정정 의미 판정 |

수집 성공은 조건 충족 법인 선정이나 추출 정확성을 뜻하지 않습니다. 최종 CI·운영 화면 근거는 이슈·PR에 남깁니다.
