# 원본·정정공시 연결 조사

## 한 줄 요약

공식 DART 자료와 실제 원본·정정 한 쌍으로 연결 근거를 확인했습니다. 같은 보고서라는 확인과 조회 항목의 변경 영향 확인을 분리하며, 자동 연결 코드는 아직 없습니다.

## 지도에서의 위치

법인·공시 찾기(B)에 필요한 조사입니다. 처리 단계의 구현 상태는 바뀌지 않았습니다. 현재 공시 후보 계약의 여러 후보 보류는 그대로입니다.

## 무엇이 달라졌나

| 전 | 후 |
|---|---|
| 정정 연결 방법 미조사 | 검색 API의 정보·한계와 실제 정정표·뷰어 관계를 대조 |
| 정정 제목이나 최신 제출일로 고를 위험 | 원본 연결·항목 영향·공시 마감·유효성을 따로 확인하는 명세 |
| 후속 사례가 없음 | HD건설기계 사업보고서 한 쌍과 검증 계획 기록 |

실제 정정은 연결 주석의 태깅 방식 변경을 기재했습니다. 이것만으로 현금 금액의 변경·불변을 단정하지 않았습니다. 관찰 해시는 뷰어·선정 구간 해시이며 전체 XML/ZIP 해시가 아닙니다.

## 누가 무엇을 정했나

**사용자가 정한 것**

- 최신 유효 정정을 반영하되 동일 법인의 같은 보고서 관계와 항목·기간·범위를 확인합니다.
- 제목·제출일만으로 원본을 덮어쓰지 않고 불명확하면 근거를 보존해 보류합니다.
- 공식 자료와 실제 사례로 먼저 조사하며 클로드의 수집·추출 평가와 이슈를 나눕니다.

**조사 중 에이전트가 정한 것**

- HD건설기계의 원본 20260318001192와 정정 20260602000456을 개발용 조사 사례로 골랐습니다.
- 원문 표지·정정표와 양쪽 뷰어의 본문 관계를 대조하고 작은 정정표 응답과 관찰 메타데이터를 보존했습니다.
- 미구현 연결기에 통과하는 형식적인 테스트를 추가하지 않고 후속 검증 사례를 계획으로 표시했습니다.

## 확인해 주세요

이번 조사 반영을 위해 추가로 판단할 것은 없습니다. 여러 차수·첨부정정·미변경 항목 재사용은 사례를 더 확보한 뒤 실행 계약을 정하며 현재 자동 선택 규칙으로 넣지 않았습니다.

## 확인한 것과 못 한 것

| 확인한 것 | 못 한 것 |
|---|---|
| 공식 가이드의 검색·원문 정보와 실제 한 쌍의 법인·최초 제출일·본문 관계 | 모든 정정 유형·여러 차수·철회 관계 |
| 원본 사업기간과 정정표의 변경 항목, 선정 구간 응답 해시 | 현금 수치 변경/불변과 전체 변경 후 본문·첨부 영향 |
| 문서·관찰 기록과 기존 안전한 보류 동작 유지 | 완전한 XML/ZIP 기반 연결기·항목 적용 구현 |

검사·병합·배포 근거는 이슈·PR에 남깁니다. 후속 검증 계획을 구현 정확도 검증 완료로 집계하지 않습니다.
