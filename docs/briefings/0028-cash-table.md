# 재무상태표에서 현금 금액 읽기

## 한 줄 요약

미리 골라 둔 재무상태표 HTML에서 현금 금액을 읽어 계약 형식으로 돌려줄 수 있게 됐습니다. 아직 헬릭스미스 한 곳의 서식만 확인했습니다.

## 지도에서의 위치

```mermaid
flowchart LR
    C[원문 수집] --> D[현금 행·열 추출]
    D --> E[단위 정규화]
    E --> F[계약 검증]
    classDef changed fill:#dbeafe,stroke:#2563eb,stroke-width:3px
    classDef same fill:#f9fafb,stroke:#d1d5db
    class D changed
    class C,E,F same
```

D 단계가 미구현에서 **일부**로 바뀌었습니다. 앞 단계(C)가 표를 골라 주는 것은 아직 사람이 해야 합니다.

## 무엇이 달라졌나

| 입력 | 결과 |
|---|---|
| 헬릭스미스 별도 재무상태표, 2025-12-31 요청 | 31,653,154,838원 |
| 헬릭스미스 연결 재무상태표, 2025-12-31 요청 | 31,827,123,947원 |
| 단위가 지워진 표 | 확인 필요 (금액 없음) |
| 별도 요청에 연결 표를 넣음 | 확인 필요 (연결 금액으로 대체 안 함) |
| 표에 없는 날짜 요청 | 확인 필요 (전기 금액으로 대체 안 함) |

## 누가 무엇을 정했나

**이슈 #19에서 정한 것**
- 미리 골라 둔 구간만 입력으로 받습니다. 보고서 전체에서 표를 찾는 일은 하지 않습니다.
- 날짜·단위·행이 모호하면 금액을 추정하지 않고 확인 필요로 둡니다.

**구현 중 에이전트가 정한 것 (이슈에 없던 것)**
- 표 제목이 요청 범위와 맞아야 합니다. 연결 요청에는 "연결 재무상태표" 제목이 있어야 합니다.
- 구간 크기는 256KiB까지, 표는 두 개까지만 받습니다.
- 병합 셀(rowspan·colspan)은 받지 않습니다.

## 확인해 주세요

1. **병합 셀을 거절하는 것이 맞나요?** 다른 법인 서식에 병합 셀이 흔하면, 대부분이 확인 필요로 떨어질 수 있습니다.
2. **표 제목으로 범위를 확인하는 방식이 괜찮나요?** 제목 표기가 법인마다 다르면 정상 표도 거절될 수 있습니다.

## 확인한 것과 못 한 것

| 확인한 것 | 못 한 것 |
|---|---|
| 실제 원문 두 구간에서 기존 정답과 같은 금액 | 다른 법인·다른 서식 |
| 전기 열을 첫 숫자로 잘못 읽지 않음 | 보고서에서 표를 자동으로 찾기 |
| 단위·기간 누락, 중복 행, 병합 셀에서 금액이 나오지 않음 | 주석 표, XBRL, PDF |
| Python 125개 테스트, 타입·린트·문서 빌드 통과 | 정정 공시 선택 |
