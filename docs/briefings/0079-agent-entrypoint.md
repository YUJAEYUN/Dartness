# AGENTS.md에서 작업 경로를 바로 찾기

## 한 줄 요약

기존 제약을 유지하면서 작업 시작·문서 안내·검증·승인·마무리 순서로 AGENTS.md를 재구성했습니다.

## 지도에서의 위치

개발 에이전트의 작업 진입점 개선입니다. DART 처리 단계와 위임 권한은 바뀌지 않았습니다.

## 무엇이 달라졌나

작업별 문서 표와 Python·문서·대시보드 검증 명령을 바로 찾을 수 있습니다. 상세 기준은 기존 docs로 연결하고 원문 정답·DART 도구·승인·병합 제약은 유지했습니다. 기존 지침의 보존 위치와 대표 작업 여섯 개의 경로를 문서로 대조했습니다.

## 누가 무엇을 정했나

**사용자가 정한 것**

- AGENTS.md를 모든 절차를 쌓는 문서보다 필요한 문서·검증·승인 경로로 안내하는 진입점으로 개선합니다.
- 기존 제약을 빠뜨리지 않고 효과를 구분해 검토합니다.

**구현 중 에이전트가 정한 것**

- 새로운 Skill·Hook·하위 AGENTS 파일 대신 기존 가이드와 위키를 재사용했습니다.
- 줄 수 목표는 두지 않고 기존 지침 묶음별 보존 대조를 남겼습니다.
- 여섯 작업의 경로는 같은 에이전트가 수동 판독했고 독립 실행 성능 측정으로 표현하지 않았습니다.

## 확인해 주세요

추가 결정은 없습니다. 위임 정책·기존 정답·CI·권한을 바꾸지 않았습니다. 독립 에이전트 A/B 실험은 별도 작업이며 이번에 수행하지 않았습니다.

## 확인한 것과 못 한 것

| 확인한 것 | 못 한 것 |
|---|---|
| 기존 지침의 보존 위치와 문서 연결 대조 | 실제 에이전트 탐색 속도·승인 누락 감소 |
| 버그·새 조회·정답 변경·검사 완화·외부 DART 도구·문서 충돌의 경로 수동 검토 | 깨끗한 환경의 독립 A/B 실행 |
| 기존 CLAUDE.md의 @AGENTS.md 연결 유지, 문서·생성물 검사 | 다른 컴퓨터의 Claude 세션에서 실제 로드 여부 |

검사 통과는 지침 준수나 의미 정합성을 보증하지 않습니다. 최종 CI·운영 반영 근거는 이슈·PR에 남깁니다.
