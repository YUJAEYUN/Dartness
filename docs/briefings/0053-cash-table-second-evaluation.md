# 현금 표 추출 두 번째 평가

## 한 줄 요약

고친 현금 표 추출기를 처음 보는 5개 법인(9건)으로 다시 평가했습니다. 틀린 금액은 없었고 8건이 원문에서 정한 정답과 같았습니다. 금융업은 재무상태표만으로는 현금및현금성자산을 알 수 없어 확인 필요로 끝납니다.

## 지도에서의 위치

```mermaid
flowchart LR
    C[원문 수집] --> D[현금 행·열 추출]
    D --> E[단위 정규화]
    classDef changed fill:#dbeafe,stroke:#2563eb,stroke-width:3px
    classDef same fill:#f9fafb,stroke:#d1d5db
    class D changed
    class C,E same
```

D 단계의 상태는 "일부" 그대로입니다. 바뀐 것은 검증 근거입니다. 개발에 쓰지 않은 법인으로 한 평가 결과가 처음 생겼습니다.

## 무엇이 달라졌나

| 결과 | 건수 | 사례 |
|---|---|---|
| 정답 금액 | 2 | 이크레더블 별도·연결 |
| 정답대로 확인 필요 | 6 | KB금융·삼성화재·키움증권 별도·연결 |
| 금액이 있는데 확인 필요 | 1 | 대한약품 개별 |
| 틀린 금액 | 0 | |

- **금융업:** 재무상태표에 "현금및예치금"만 있습니다. 이 값은 현금및현금성자산과 다릅니다. KB금융 연결 기준으로 현금및예치금은 34조 7,769억 원이고, 현금흐름표의 기말 현금은 29조 206억 원입니다.
- **대한약품:** 계정명이 "(5)현금및현금성자산"처럼 앞에 항목 번호가 붙어 있어 현금 행을 찾지 못했습니다.

## 누가 무엇을 정했나

**사용자가 정한 것**
- 12월 결산 5곳(KB금융, 삼성화재, 키움증권, 대한약품, 이크레더블)만 바로 수집하고, 12월이 아닌 결산 법인은 뺍니다(2026-11-23).
- 금융업은 요구사항대로 확인 필요를 정답으로 둡니다. 현금흐름표 값은 참고로만 기록합니다(A안, 2026-11-23).

**구현 중 에이전트가 정한 것**
- 후보 법인을 골랐습니다. 이전 6곳과 겹치지 않게 금융업 3곳, 코스닥 2곳으로 구성했습니다.
- 입력 구간은 첫 평가와 같이 재무상태표 제목 아래 첫 두 표를 그대로 잘랐습니다.
- 정답을 먼저 커밋한 뒤(ceb4b65) 추출기를 실행했습니다.
- 금융업 확인 필요의 이유는 extraction_failed로 정했습니다. 지원 범위 문서에서 "행 누락"을 이 이유로 분류하기 때문입니다.
- 정정 공시가 있는 법인도 첫 평가처럼 정정 전 원본을 썼습니다.

## 확인해 주세요

1. **계정명 앞의 항목 번호를 허용할까요?** "(5)현금및현금성자산"을 현금 행으로 읽게 하면 대한약품 같은 서식을 지원합니다. 고치면 대한약품 사례는 개발용이 됩니다.
2. **금융업 현금 기준을 언제 정할까요?** 정하기 전까지 금융업 현금 조회는 모두 확인 필요로 끝납니다. 현금흐름표의 기말 현금을 쓸지, 주석을 찾을지 정해야 합니다.
