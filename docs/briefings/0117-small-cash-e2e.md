# 실제 소수 법인 수집부터 엑셀까지 확인

## 한 줄 요약

공개 법인 두 곳의 새 수집과 기존 최신 현금 조회·통합 엑셀을 연결해 작은 E2E를 확인합니다.

## 지도에서의 위치

```mermaid

    A[명시한 표본·공식 법인 코드] --> B[새 이력·원문·뷰어 수집]
    B --> F[기존 최신 선택·현금 조건 검증]
    F --> I[통합 엑셀·전체 상태 기록]
    classDef changed fill:#dbeafe,stroke:#2563eb,stroke-width:3px

```

## 무엇이 달라졌나

기존 수동 수집 워크플로에 small_cash_e2e 모드를 추가합니다. 최대 두 종목을 명시하고 전체 API 20회·웹 6회로 제한합니다. 표본의 실제 기업개황·공시 목록·원문·본문을 새로 받고 기존 최신 선택과 세 열 엑셀을 재사용합니다. 모든 대상과 요청 기록·실패를 보존합니다.

## 누가 무엇을 정했나

사용자는 전수 확대 전에 작은 실제 E2E를 진행하기로 했습니다. 기존 공식 API·시크릿·데이터 브랜치·의존성을 재사용합니다. 기존 정답·판정 기준·권한을 바꾸지 않습니다. 표본 실험의 별도·최근 12개월·500억원은 제품 기본값을 새로 정한 것이 아닙니다.

## 확인해 주세요

추가 결정 요청은 없습니다. 작은 실행 경로의 확인이며 실제 전수 수집·완성된 제품 입력 템플릿·새 독립 추출 성능 평가가 아닙니다. 분기/반기 정정 등 미지원 관계는 기존처럼 보류합니다.

## 확인한 것과 못 한 것

고정 응답으로 입력 거절·실패 대상 보존·호출 한도·조건 미충족 출력을 검사합니다. 실제 새 실행의 금액·날짜·단위·호출 수·크기는 평가 기록과 이슈에 연결합니다. 전체 시장·주석 합계·Excel 데스크톱 렌더링은 검증 범위가 아닙니다.
