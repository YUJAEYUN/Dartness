# 여러 법인의 조회 상태와 엑셀을 한 번에 연결

## 한 줄 요약

받은 모집단 전체의 상태를 남기고 확인된 조건 충족 법인만 같은 엑셀로 합칩니다.

## 지도에서의 위치

```mermaid
flowchart LR
    B[모집단 전체와 법인별 자료] --> F[관측일·식별자·범위 검사]
    F --> H[기존 최신 조회로 법인별 조건 확인]
    H --> I[충족 법인 통합 엑셀·전체 감사 기록]
    classDef changed fill:#dbeafe,stroke:#2563eb,stroke-width:3px
    class B,F,H,I changed
```

## 무엇이 달라졌나

처리 한도·자료 없음·읽기 실패를 구분하고 미처리 법인을 원래 대상에서 삭제하지 않습니다. 같은 요청으로 기존 최신 현금 조회를 실행하고, 서로 다른 행의 날짜·단위·재무 범위·링크·메모를 보존합니다. 기본 표는 충족 법인만 세 열이며, 확인 내역은 기존 옵션을 켠 경우에만 별도 시트에 둡니다.

## 누가 무엇을 정했나

사용자는 기존 기준 안의 구현·검증을 위임했습니다. 새 금융 기준·선정 우선순위·API 호출·저장 정책·의존성·권한·CI 완화는 없습니다. 법인별 명시한 별도/개별 입력을 그룹 전체 값으로 대체하지 않습니다.

## 확인해 주세요

추가 결정 요청은 없습니다. 준비된 명부/자료를 연결한 개발자 API이며 실제 전체 시장의 원문을 조회한 것은 아닙니다. 미처리·확인 필요가 있으면 전체 금액을 검증했다고 표시하지 않습니다. 전수 수집·캐시·주석 합계와 최종 사용자 입력은 남아 있습니다.

## 확인한 것과 못 한 것

기존 실제 개발용 두 법인의 원문·표 HTML을 합성 명부에 연결했습니다. 두 법인은 조건 충족, 자료가 없는 합성 대상은 미처리로 남았고 엑셀은 확인된 두 행만 담았습니다. 실제 원·천원 단위와 각 표 링크를 대조했습니다. 새 독립 평가로 세지 않으며 명부를 실제 관측한 전수 실험도 아닙니다. 단일 출력의 기존 테스트와 한도·누락·오류·범위·관측일·개별 날짜/단위·선택적 확인 시트를 검사합니다.
