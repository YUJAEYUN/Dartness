# 공통 조회 정책을 문서와 화면에 반영

## 한 줄 요약

조사 대상·자료 시점·정정·엑셀 옵션의 합의를 한 곳에 모았습니다. 실행일 현재 세 시장 상장법인이 기본 대상이며, 전수 조회 엔진은 아직 없습니다.

## 지도에서의 위치

처리 단계의 구현 상태는 바뀌지 않았습니다. 입력(A)과 결과 출력(I)에 필요한 정책을 정리한 명세 작업입니다.

## 무엇이 달라졌나

| 전 | 후 |
|---|---|
| 대화에 흩어진 공통 조건 | 계약 초안과 화면에서 같은 기준 확인 |
| 요청일과 추출 날짜의 관계 불명확 | 상위 요청일·실제 자료 날짜와 대체 표시를 구분 |
| 최종 파일과 내부 확인 기록 혼재 | 기본 파일은 충족 법인만, 검토 내역은 선택 시 별도 시트 |

## 누가 무엇을 정했나

**사용자가 정한 것**

- 한 번에 한 유형, 기본은 실행일 현재 코스피·코스닥·코넥스 상장법인 전체 조사입니다.
- 금액·보유는 지정 기준일, 사건은 대상 기간을 받습니다.
- 같은 날짜 자료가 없으면 사용자 지정 경과 한도 안에서 가장 가까운 이전 자료를 사용하고 실제 날짜·대체 여부를 표시합니다.
- 실행일까지 공개된 공시와 최신 유효 정정을 사용합니다.
- 최종 엑셀은 확인된 충족 법인 위주로 만들고, 필요할 때 검토 내역을 추가합니다.

**구현 중 에이전트가 정한 것**

- 공통 정책을 별도 기준 문서의 표로 모으고 대시보드 데이터를 생성합니다.
- 하위 현금 추출 계약에는 선정된 실제 날짜를 전달하는 구조를 초안으로 설명했습니다. 상위 선택 코드는 아직 없습니다.
- 같은 문서도 명세 PR 브리핑 필수 대상에 추가했습니다.

## 확인해 주세요

이번 반영을 위해 다시 판단할 것은 없습니다. 다음 설계에서는 최대 경과 기간의 입력 단위와 경계 계산을 정해야 합니다. 아직 임의 기본값을 넣지 않았습니다.

## 확인한 것과 못 한 것

| 확인한 것 | 못 한 것 |
|---|---|
| 문서에서 정책 생성, 중복·누락 거절과 원본 변경 감지 | 실제 전수 법인 수집·날짜 선택·정정 연결 |
| 기존 추출 날짜 검증과 평가 자료 보존 | 엑셀 생성·전체 공시 정확도 |
| 문서·타입·린트·테스트·빌드로 연결 검사 | 검사만으로 의미 정합성을 자동 증명하는 것 |

실제 검사·배포 완료 근거는 PR과 이슈에서 확인합니다. 최신 평가의 원문 11건 미추출 결과도 유지합니다.
