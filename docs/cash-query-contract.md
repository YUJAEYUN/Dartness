# 현금 조회 계약 초안

상태: 조회 범위·대체 금지·이유 구분은 사용자와 합의했습니다. 아래는 첫 구현을 위한 계약 초안이며 실행 가능한 스키마나 추출기는 아직 없습니다. 원본 기준은 [현금 조회 요구사항](requirements.md#cash-scope)입니다.

## 입력과 출력

| 구분 | 필요한 정보 |
|---|---|
| 입력 | 법인 식별자, 요청한 기준일, 법인 자체 또는 연결 범위, 금액 조건 |
| 확인된 값 | 원문 금액·통화·적용 단위, 정확히 변환한 금액, 재무 기준일, 실제 별도·개별·연결 구분 |
| 근거 | 공시 접수번호·원문 URL, 절·표·행·열 또는 위치, 사용한 원문 버전 |
| 확인 불가 | 이유, 확인한 경로·시각·원문 위치, 남은 확인 사항. 금액은 미확정이며 0원이 아님 |

기본 범위는 법인 자체입니다. 기준일·조건의 기본값과 정정 공시 선택 방식, 결과 포함 정책은 아직 정하지 않았습니다. API 필드명과 내부 상태 코드는 구현 전에 고정합니다.

## 실패와 확인 불가의 구분

| 상황 | 기대 처리 | 금지할 처리 |
|---|---|---|
| API에 값이 없음 | 원문 추가 확인이 필요하다고 기록 | 자료 자체가 없다고 확정 |
| 해당 공시에 재무제표가 없음 | 문서의 한계와 확인 위치 기록 | 법인 전체에 자료가 없다고 단정 |
| 요청 시점 자료를 못 찾음 | 확인한 시점과 요청 시점 구분 | 이전 기간 금액을 요청 시점 금액으로 표시 |
| 표·단위 해석 실패 | 추출 실패 이유와 원문 보존 | 단위 추정, 0원 처리 |
| 별도·개별 확인 불가, 연결은 존재 | 요청 범위를 유지하고 확인 불가 기록 | 연결 금액으로 자동 대체 |

조회 통신 장애는 자료 부재와 구분합니다. 확인 불가를 조건 미충족으로 단정하거나 누락시키는 정책도 아직 채택하지 않았습니다.

## 구현 전에 준비할 검증 사례

법인 자체 금액과 연결 금액이 다른 사례, 연결 없이 개별만 있는 사례, API 누락 후 원문에서 확인되는 사례, 요청 시점 부재, 단위 해석 실패를 준비합니다. 각 정답은 원문과 위치를 먼저 확인합니다. 아직 이 사례들의 정답 자료나 추출 테스트를 확보했다고 주장하지 않습니다.

헬릭스미스 개발용 사례의 연결 금액은 연결 선택의 검증 자료로 유지합니다. 기본 범위가 바뀌었다고 기존 연결 정답을 별도 정답으로 바꾸지 않습니다. 다음 구현 이슈에서 버전 있는 입력·출력 스키마와 실패 상태, 고정 사례를 준비한 뒤 추출기를 구현합니다.
