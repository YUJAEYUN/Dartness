- [문서 시작](docs/index.md)
- [합의한 요구사항](docs/requirements.md)
- [다음 작업](docs/work-state.md)
- [문서 실행·검사·게시](docs/documentation.md)

사람이 읽는 docs가 프로젝트의 기준입니다. 문서 사이트와 LLM 위키는 같은 원본을 사용합니다. 게시 워크플로는 수동이며 GitHub Pages 설정이 필요합니다.
